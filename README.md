# 货场 1v1 · COD-Lite

一个网页版、像素风的第一人称射击游戏：只做「货场（Shipment）」一张图，1v1 联机，纯静态零依赖。

> 当前进度：**M3 已完成**（完整对局：暂停菜单、结算数据、联机延迟补偿与弹药同步）。
> 单机人机（3 个 bot）与联机共用同一份模拟代码，见 [DESIGN.md](DESIGN.md)。

## 联机怎么玩

1. 双方打开 https://ppeqwsax.github.io/cod-lite/ ，模式选「**联机对战**」；
2. 一方点「创建房间」，拿到 5 位房间码（也会显示一条邀请链接）；
3. 把**房间码**或**邀请链接**发给朋友——对方打开链接会自动进房，或者手输房间码点「加入房间」；
4. 两边都连上后自动开局，先到 25 杀或 5 分钟结束。

- 连接是 **P2P 直连**（WebRTC），左上角会显示「房主/客机 · 直连 · Nms」；如果直连打不通会 5 秒后退回「中转」，延迟会高一些；
- 房主负责权威计算（60Hz），客机本地先预测自己（0 延迟手感），再用快照校正；
- 联机时按 Esc 不会暂停（只有自己停手），对手掉线 8 秒会提示「连接中断」。

## 玩法与操作

| 按键 | 作用 |
| --- | --- |
| `W` `A` `S` `D` | 移动 |
| `Shift` | 冲刺 |
| `空格` | 跳跃 |
| `Ctrl` / `C` | 蹲下；冲刺中按下 = 滑铲 |
| 鼠标 | 转向 + 俯仰（点击画面锁定指针） |
| 左键 | 射击 |
| 右键 | 开镜（视野收窄、扩散减半、移速降低） |
| `R` | 换弹 |
| `1` / `2` | 切换 M4A1 / M9 |
| `Esc` | 退出指针锁定（自动暂停） |

武器：**M4A1**（全自动，30 发弹匣，26 伤）、**SPR-208**（栓动狙击，5 发，**胸部一枪致命 112 伤**，开镜 0.46s / 26° 视野 / 扩散 0.02）与 **M9**（半自动，12 发，34 伤）；主武器可在主菜单切换（`1` 切主武器、`2` 切手枪）。生命 100，5 秒未受伤后自动回血。

## 技术要点

- **渲染**：Canvas 2D 软件光栅化。480×270 内部分辨率，DDA 射线 + 地板/天花板投射，`image-rendering: pixelated` 放大；贴图是仓库里的 64×64 PNG，运行时预生成 16 级明暗。
- **贴图**：全部由 `tools/gen-textures.js` 程序生成（手写 PNG 编码，零依赖），可随时重新调色/重绘。
- **模拟**：固定 60Hz，`sim.js` 是唯一的权威逻辑，单机与联机共用同一份代码。
- **体积**：全部代码 + 贴图约 60KB，无框架、无构建、无 CDN。

## 本地运行

```bash
node tools/serve.js . 8128     # 仓库根目录起一个静态服务
# 浏览器打开 http://127.0.0.1:8128
```

直接用 `file://` 打开也可以，只是贴图需要走本地服务（部分浏览器会拦 `file://` 的 canvas 像素读取）。

## 目录

```

js/hud.js             # 准星与 HUD
js/main.js            # 装配与主循环
```
