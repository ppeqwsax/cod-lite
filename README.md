# 货场 1v1 · COD-Lite

一个网页版、像素风的第一人称射击游戏：只做「货场（Shipment）」一张图，1v1 联机，纯静态零依赖。

> 当前进度：**M1 已完成**（单机 bot：巡逻 / 索敌 / 点射 / 重生，先到 25 杀或 5 分钟结束）。
> M2（P2P 联机）、M3（完整对局打磨）在路上，见 [DESIGN.md](DESIGN.md)。

## 玩法与操作

| 按键 | 作用 |
| --- | --- |
| `W` `A` `S` `D` | 移动 |
| `Shift` | 冲刺 |
| 鼠标 | 转向（点击画面锁定指针） |
| 左键 | 射击 |
| `R` | 换弹 |
| `1` / `2` | 切换 M4A1 / M9 |
| `Esc` | 退出指针锁定（自动暂停） |

武器：**M4A1**（全自动，30 发弹匣，26 伤）与 **M9**（半自动，12 发，34 伤）。生命 100，5 秒未受伤后自动回血。

## 技术要点

- **渲染**：Canvas 2D 软件光栅化。480×270 内部分辨率，DDA 射线 + 地板/天花板投射，`image-rendering: pixelated` 放大；贴图是仓库里的 64×64 PNG，运行时预生成 16 级明暗。
- **贴图**：全部由 `tools/gen-textures.js` 程序生成（手写 PNG 编码，零依赖），可随时重新调色/重绘。
- **模拟**：固定 60Hz，`sim.js` 是唯一的权威逻辑，单机与联机共用同一份代码。
- **体积**：全部代码 + 贴图约 60KB，无框架、无构建、无 CDN。

## 本地运行

```bash
node tools/serve.js . 8128     # 仓库根目录起一个静态服务
# 浏览器打开 http://127.0.0.1:8128
```

直接用 `file://` 打开也可以，只是贴图需要走本地服务（部分浏览器会拦 `file://` 的 canvas 像素读取）。

## 目录

```
index.html
css/style.css
assets/tex/*.png      # 集装箱/木箱/地面/枪械等贴图
js/core.js            # 常量、工具、武器数值
js/map.js             # 货场地图（32×32 格，180° 对称）
js/raycast.js         # 软件射线渲染器
js/entities.js        # 玩家状态
js/sim.js             # 权威模拟（移动/射击/换弹/碰撞）
js/input.js           # 键鼠 + 指针锁定
js/hud.js             # 准星与 HUD
js/main.js            # 装配与主循环
```
